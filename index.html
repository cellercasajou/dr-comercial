Sincronització al Núvol (Google Firebase)

🔥 Sincronització en Temps Real amb Google Firebase: Qualsevol canvi fet al mòbil o a l'ordinador s'actualitza instantàniament a tots els dispositius al mil·lisegon sense haver de recarregar.

Com crear el projecte a Google Firebase (Gratuït):

  1. Entra a console.firebase.google.com amb el teu compte de Google.
  2. Prem "Crear un projecte" (anomena'l dr-comercial).
  3. A la secció Compilació > Firestore Database, fes clic a "Crear base de dades" (mode de prova).
  4. A Configuració del projecte ⚙️ > Afegeix una aplicació Web (icona </>) i enganxa el codi aquí.
Sincronització amb Supabase: Base de dades PostgreSQL per a qui prefereixi Supabase.
